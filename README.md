# miniclaw

面向个人创作者与电商内容制作的 AI 产品宣传工作台。

从商品资料、产品图片到口播文案、封面与短视频，miniclaw 将创意讨论、素材整理、图片编辑和视频制作放在同一个项目中，帮助用户逐步把想法变成可预览、可修改、可导出的作品。

## 项目背景

在产品宣传创作中，资料整理、卖点提炼、文案撰写、商品修图和视频剪辑往往分散在多个工具里。素材、对话与作品版本相互割裂，修改一个环节时，常常需要重新传递背景、寻找文件和核对版本。

miniclaw 源于个人 AI 智能体工程学习与电商业务实践，希望围绕真实商品资料，把这些创作环节连接起来：用对话梳理需求，用画布组织素材与镜头，用编辑和生成工具制作内容，并保留讨论过程与作品版本，方便持续调整。

项目目前聚焦个人产品宣传创作，覆盖商品图、宣传封面、口播脚本与短视频等常见场景。

## 主要功能

### AI 创作搭档

内置创作助手 **Luka**，协助讨论宣传方向、梳理商品卖点、优化文案与提示词、设计分镜，并结合项目素材推进创作。围绕真实商品信息开展工作，区分已有事实、创意建议与待确认内容。

### 商品资料与附件分析

支持上传图片、PDF、Word、Excel、CSV 及文本、字幕文件，进行内容查找、资料整理、摘要与结构化计算。资料可以随对话保存，便于在后续创作中继续参考。

### 自由创作画布

在同一项目中组织素材、方案、备注与镜头，通过节点和连线表达创作关系。画布与项目对话相互关联，方便从整体方案进入具体素材或镜头的修改。

### 商品修图与封面设计

提供裁剪、旋转、调色、缩放等基础编辑，以及图片、文字、形状图层与局部选区。支持接入 AI 图片编辑，比较候选结果、采用合适版本，并将素材带回聊天或画布继续使用。

### 口播、字幕与视频制作

协助打磨口播脚本、宣传文案和镜头提示词，支持视频生成、配音、字幕与成片合成。可对已采用的视频进行头尾裁剪、分割、排序和转场调整，预览时间线并导出作品；平台发布由用户自行完成。

### 素材与作品版本管理

保存项目素材、生成结果和编辑历史，支持版本比较、恢复、下载与打包。候选结果经用户采用后再更新对应素材，便于尝试不同方案并保留已有成果。

### 对话与个性化配置

支持流式对话、工具执行详情、历史恢复，以及会话搜索、改名、归档和草稿保存。可管理技能、模型与工具配置，按需维护长期记忆；工作台提供管理员登录入口。
