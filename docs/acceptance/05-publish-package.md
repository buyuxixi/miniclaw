# 第五步验收报告：发布包与平台边界

日期：2026-10-03。状态：本机发布包完成、真实ZIP验证通过；平台自动发布未实现。

## 实现流程

当前素材对应的有效MP4＋已保存发布文案 → 检查revision与成片签名 → 创建全新ZIP → 写入视频、可选封面/字幕、facts/script/caption文本、manifest → 返回认证下载。重复打包保留旧版本，正文/封面/SRT/成片改变后旧包标过期。旧成片或空文案不能打包。

manifest记录`ready_for_manual_publish`、素材名称/字节数/hash、录制来源备注、输出尺寸/时长与任务版本，不包含凭据或本机绝对路径。成片输出丢弃原素材容器元数据/章节，避免默认携带录制文件的私人标题等字段；字幕和稿件按用户选择进入包。ZIP不包含原视频、透明MOV、外部工作台源码、字体、二进制或任何Key。

## 已执行验证与自查

真实服务生成发布包，解包后的MP4与下载成片字节一致、封面与上传PNG字节一致；manifest状态为待人工发布，输入素材hash全部未变。自动检查覆盖空文案/旧成片拒绝、标题改动使包过期、跨服务实例恢复。浏览器实际替换封面、生成新包、显示新版下载入口通过。

自查后添加了历史版本选择下载与输出元数据清除。带私人测试标题的源视频经真实FFmpeg合成，输出探测不再包含该标题，回归断言通过。进度中的“发布包完成”不会展示为“平台已发布”。

## 用户验收步骤

1. 下载并解压发布包，打开`video.mp4`，核对尺寸、声音、字幕与封面；阅读`caption.txt`及`manifest.json`。
2. 核对真实商品事实、素材许可和平台所需信息，在平台自己的创作界面选择视频/封面并填写文案。
3. 发布前人工预览，发布后将实际链接自行留存。目前应用不会代发、查审核或读取收益。
4. 修改文案/封面后重新生成包，确认旧包保留但不再是当前版本。
