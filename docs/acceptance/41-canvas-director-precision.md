## 本轮完成

- 连线删除全部节点/面板避让，仅由两端真实端口生成一条三次曲线。路由缓存也仅含端点；点击选中、打开编辑器或移动无关节点不改道。保留关联路径按帧拖动预览。
- 整理使用节点实际宽高，参考图片与镜头/结果分列，结果保留对应关系，清除选中并支持撤销。桌面整理最低 55% 工作缩放；大图或较多节点可能需要平移。“全览”仍可显示全部，二者用途分开。
- 底部入口明确横向排列，36px hover 区域同时容纳图标和文字；添加菜单提升到节点编辑卡之上。
- 导演面板贴紧顶栏，移除空白遮罩条。参考卡固定宽度、序号缩略图及单行省略标题，完整标题可悬停查看；消息自动换行，输入和操作收紧。
- 精修工具采用统一 SVG。项目要求、裁剪/画幅、模型费用折叠，默认突出图片、修改要求和生成候选。文件名只在头部显示一次；收费与保真说明仍可展开查看。
- 比较页改为“采用这次修改？”，动作是“保留当前图”和“采用并回画布”；只保留更新图片输入及已有视频保留的必要说明。
- 水平/垂直翻转的单一明确指令直接调用现有本地图片编辑能力，并提供水平翻转按钮。多图镜头先选目标，版本检查和进行中互斥避免重复操作；完成后比较再采用，可撤销。否定、复合修改和描述性问题仍走正常讨论，不误判为翻转。
