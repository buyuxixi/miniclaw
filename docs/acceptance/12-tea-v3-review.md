## 镜头与声音如何改进

采用Anna Pou两段同场景实拍，镜头按照动作开场→茶汤细节→人物环境→手部细节→动作结束→海报式片尾展开。两个片段含淡/浓茶汤与不同玻璃壶，因此用「淡一点，浓一点」组织同场景蒙太奇，未冒充某款商品的一次连续使用。没有虚构价格、效果或人物代言。素材和方法来源见第十步。

| 镜头区间 | 目的/画面 | 配音区间（真实WAV测时） |
|---|---|---|
| 0–3秒 | 水流入杯，直接用动作开场 | 0.350–2.670：「先别急，给自己倒一杯茶。」 |
| 3–6.2秒 | 茶汤与玻璃细节 | 4.752–7.792：「看茶汤落下来，光也落进杯里。」跨到下一镜头形成延续 |
| 6.2–10.7秒 | 人物、两只壶、日常环境 | 9.875–12.915：「淡一点，浓一点，都有自己的节奏。」 |
| 10.7–14.9秒 | 手部/茶具细节 | 配音延续与画面留白 |
| 14.9–20秒 | 放下壶，动作结束后停留 | 14.997–17.717：「日常的小事，也可以慢慢来。」 |
| 20–23秒 | 真实茶具定格与中文楷体标题 | 19.800–21.800：「把这一刻，留给自己。」之后留1.2秒 |

配音使用已有北京百炼Key，`qwen3-tts-instruct-flash`/Serena，固定自然温柔指令；五句实际生成音频在节奏与片尾修正时全部复用。背景声是本次脚本原创合成的稀疏五声音阶配乐，没有使用平台他人音乐；不宣称是真人钢琴录音。声音通过原生模式混合与旁白压低。

国风视觉方向保留在片尾的楷体、纸色底与克制留白；视频主体采用实拍。未套用海报Skill改造所有交互控件。本轮工作台增加制作方式、固定音色及背景音开关，整体UI保持前轮五步骤布局，没有声称又完成一次完整UI改版。

## 自查发现与修复

1. **P2，真实指令配音不能下载。** 旧下载许可仅适配Flash结果桶，Instruct实际返回不同北京OSS桶。先做一次短句诊断确认真实host，只增加该精确host，保留HTTPS、禁止跳转与伪域名拒绝。真实五句下载及成片成功。首次失败与诊断均可能计费，未自动重试/切Key，后续编辑不新增语音请求。
2. **节奏问题，原生第一版说完后有长空尾。** 五句结束约14.59秒，23秒片尾剩余约8秒。改为按实际WAV与镜头片总长分配句间留白（本例2.082秒），最后一句21.8秒结束；重做全部复用已完成音频。回归核对新句间及末句时间，源片时长保持。
3. **视觉问题，楷体多行间距失衡。** 实际解码片尾发现字体行度量使两句隔得过远，改为两行独立定位，重新导出封面/预剪片。实际上传后旧视频和旧包被判过期；最终生成同版视频与包，旧版本保留。
4. **音轨回归风险。** 背景音合成不能对原音轨直接归零而丢延迟。复用已验证偏移修正，真实FFmpeg 0.6秒偏移检查通过；默认替换模式不混回原轨，无原轨的保留请求在TTS前拒绝。
5. **控件布局。** 实机发现背景音勾选继承表单label纵向布局，增加显式横向排列，让勾选与说明同行。构建/创作前端9项复验与窄屏检查通过。
6. **开头标题对比度。** 解码1秒帧发现深色楷体与移动茶壶背景混在一起。移除重复的开头标题，由倒茶动作、旁白和同版字幕开场；保留片尾标题。重新上传源片、重做与打包，仍复用五句声音。

在本次检查范围内未发现未解决的阻断或重要缺陷。确认的限制仍保留：单句或非常长镜头片可能留长尾，逐句模型生成不保证全段表演一致，字幕不是逐字ASR，句间分配不是画面语义/切点识别，素材预算与单机队列沿用原有边界。

## 用户验收步骤

1. 直接播放成片，对比上一版：看真实动作是否改善视觉，听Serena配音是否自然，评估镜头及旁白留白是否仍显得拖沓。无需先安装新库或Skill。
2. 看片尾标题、人物/茶具连续性、字幕大小和位置；它是生活方式素材练习，不是具体商品广告。若后续带货，先换自己的商品素材和可核对事实。
3. 打开同名原生项目，查看主稿、封面、镜头片、Serena和背景音勾选，播放最终视频；核对导出包确实是当前版本。
4. 解压包查看video、cover、SRT、script、facts、caption、manifest，再由用户自行发布。
