# 2026-10-06 — 作品工作台与真实对话记录重构

用户指出3号样稿会话抽屉混淆项目与会话，并明确授权更大胆重构。本轮已进入真实 React 应用，9120读取新版构建；旧9135对比页保留为历史方向，并提供新版入口。使用 Oil UI Pro 0.16.0 的既有项目、布局、设计工作区及独立评审协议，结合开发实施与审查技能。不是另交一份静态样稿。

## 实际变更

- 创作页删除长期会话侧栏与遮挡式抽屉，改成顶部项目导航、左侧作品工作台、右侧持续 Agent 对话。修图、口播、视频是主任务；商品方向与项目资料是上下文入口。
- 对话记录从本项目实际用户消息生成，倒序展示任务和原请求摘录，点击回到对应消息。记录模式收起输入框，返回恢复滚动；没有增加新的后端会话模型或伪造时间字段。
- 修图的原图参考、当前工作图、工作版本、采用图状态和采用/精调操作集中在工作区。参考原图不改变真正的工作图工具目标。采用图已保存只表示项目存在采用图，不表示当前预览与采用图逐像素相同。
- 口播以可读主稿为主区域，保留一次采用状态；继续打磨带入候选稿要求，确认后才替换主稿。相同正文的历史回复标注“与主稿一致”，表示内容相等，不推断采用来源；不同候选仍保留采用入口。跨项目/归属及待复核稿不使用这一状态。
- 视频以成片预览、素材设置、下载/合成为主区域，长说明折叠。原有素材、配音额度、能力校验、失败与取消流程保留。
- 看板采用同一顶部导航和控件尺度，减少卡片内边框与重复说明。各步骤直接显示“已确认/已采用/已完成/待完善”，已有成片的项目主按钮直接“查看成片”，不因早期步骤缺项建议重修图片。自由对话明确创建独立 Chat，学习 Agent 不要求建立商品项目。
- 手机将任务与对话/作品切换排成一行，项目名和资料独立一行；390px顶部由约244px收紧到171px。桌面工作区和对话并排，手机通过显式切换共享空间。
