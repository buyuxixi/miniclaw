实际使用 [TVC Director](https://github.com/Ethanxwang/tvc-director) 固定MIT提交593149aba220361bd2c3e9059516c890081ada00（已保存私有参考）：产品优先、物理光线、材质微距、光影发展、干净片尾。原Skill绑定Nano Banana/Seedance；本次只采用镜头方法，依据实际工具重新写imagegen/万相提示，不宣称用了原绑定模型。director-skills既有lighting资料约束反射、方向与接触阴影；mono的限制色彩/留白方法延续到绿色、银色与米白标签。国风海报不强行混入这一条护肤产品广告。

## 制作流程

1. 内置imagegen生成 `hero.png`：受控条形柔光、绿色透光玻璃、银盖反射、水面及背后玻璃层次。主瓶清晰，顶部/底部留字空间。
2. 以hero为参考，imagegen引用编辑生成 `macro.png`：透明滴管、一颗悬垂液滴、绿色液体表面。安排液滴下落距离，为真实运动生成提供条件。
3. 同样引用hero编辑 `wave.png`：瓶型/盖/标签保持，替换背景为透明液体波浪；液体绕开标签。
4. 逐张检查后保存到项目输出目录。`image-assets.json`记录hash/尺寸；`image-prompts.json`保存完整三条提示。内置工具不暴露精确模型ID；不是百炼生成这些静态首帧，也没有使用用户OpenAI API Key。
5. 新增可复现样片脚本 `scripts/produce_serum_v4.py`。默认只读；显式 `--submit 1/2/3` 才向已有北京百炼Key提交图生视频，最多三次POST。任务ID先存，`--poll`只查询/收集，未知提交不能自动重复买任务。

三个首帧均941×1672/RGB。它们是图生视频输入，不将其描述为原生1080P视频；后续必须核对实际生成视频尺寸。
