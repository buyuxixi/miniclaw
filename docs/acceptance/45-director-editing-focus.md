# 导演与生成编辑区减负

2026-10-08。用户指出说明、来源、同步条与重复入口堆叠，让生成面板和导演侧栏同时争抢空间。本轮先用 oil-ui-pro 进行隔离审查，再调整现有暗色媒体工作区。

## 方向与改动

采用单一编辑焦点：浮动生成栏保留输入图片、提示词、模型、规格、价格与生成；进入优化时收起浮动栏。对象名称、缩略图与“镜头／视频结果”身份在侧栏只出现一次。相比继续双编辑器减字，这个方向能减少入口判断与重复阅读，并延续现有画布风格。

- 删除常驻“已同步选中对象”、正常连接状态、来源文件名墙、重新生成来源说明和重复导演按钮。来源详情与当前旧词按需展开；核对、完整编辑和删除移入更多菜单。更多菜单支持方向键与 Esc 回到触发按钮。
- 打开优化先输入修改要求。旧词默认折叠；本次候选直接显示简短修改说明，只显示一份正文。“新提示词／原提示词”切换时回顶，长文只有主区域滚动。采用按钮固定写“采用建议并返回”，避免在原词页签误解采用对象。
- 继续调整保留上一轮目标并基于候选重写；未发送成功时保留候选与新草稿。采用成功收到画布确认后返回生成栏；保存失败保留候选，并明确重试采用建议。原词被另一处修改时禁止采用，重新读取仍保留建议且禁止覆盖，需重新优化。
- 手机生成底栏保留模型、9:16、768P、5秒与预估金额。打开侧栏后，真实所选结果保持可见；定位短过渡不会影响拖动，减少动画偏好直接切换。

未更换品牌、后端计费和生成契约；未自动改用户提示词、视频或采用状态。本轮候选交互与失败状态以独立夹具验证，真实产品仅打开、选择和查看，未调用收费模型或点击生成。真实模型效果、实际账单、用户项目真实采用后刷新持久性不列为本轮新验证结论。

## 验证

最终连续三轮：每轮前端53项通过，TypeScript退出0；现有9120运行方式需要更新前端dist，最终构建通过。范围是 studio-operations、director-actions、studio-director-context 三组，覆盖结果归属、保存防覆盖、草稿目标、采用确认、发送失败、继续调整、比较切换与冲突后禁止采用。没有将全应用列为通过。

真实1440×1000、390×844入口截图，候选与失败使用400×920、390×844；长标题、长原词及2倍像素检查通过本轮布局检查。截图报告无控制台错误、页面横向溢出、坏图。实际更多菜单方向键与Esc焦点恢复已走查。

独立存量评审与任务走查不打分。第一轮指出旧词压过输入、比较顺序长读、失败恢复竞争、手机缺规格；修改后复核确认解决。第二轮指出原词页签的采用对象含糊和画布瞬时跳动，再做按钮语义与短过渡调整。最终局部复核确认按钮对象、冲突保护、重新优化恢复、失败后重试成功返回及定位过渡；本轮限定范围无残余阻断，详见证据目录 review-final.md。
