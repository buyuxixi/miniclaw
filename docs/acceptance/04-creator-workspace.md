# 第四步验收报告：固定创作任务

日期：2026-10-03。状态：实现完成、程序与实机验证通过、用户体验待最后串行验收。

## 实现流程

侧栏“创作工作台” → 新建任务 → 保存商品事实、口播稿、来源备注和输出选项 → 带入现有Chat草稿并选口播优化Skill → 人工发送/保存主稿 → 现有图片工作区制作封面、导出并上传 → 上传录制视频/同版字幕/动效JSON或透明MOV → 本机合成 → 发布包。

这是五个固定步骤的资料与产物工作台。进度表示已有资料/产物，不表示质量已经人工验收。Chat仍使用同一Hermes；这里没有另外的Agent、自动调研选品或通用流程编排器。Chat回填不自动发消息，主稿回到任务仍需人工复制保存；修图复用已有模块，封面通过文件交换连接。录制、字幕生成、配音不是新增应用功能。

数据存在原profile的`miniclaw.sqlite3`新表`creator_projects/creator_jobs`，素材在`.hermes/creator/任务ID/`。所有媒体不可变，以随机ID而非用户路径执行；替换素材仅替换当前引用，不覆盖旧文件。任务revision单调递增、事务CAS防止旧页面覆盖新内容。视频素材/比例/合成方式签名改变时旧成片过期；稿件/标题/封面改变时旧发布包过期。历史成片和包可选择查看、下载。

服务一次合成一个视频，后台执行、可取消。取消/重启不发布迟到结果，不自动重做。执行器捕获错误保存失败状态。每任务存储预算1 GiB，合成预留128 MiB、编码限制视频码率，最多20份成片/20份包；旧文件不自动删除，达到预算另建任务。任务列表目前展示最近100项。

实现入口：`miniclaw_web/creator.py`（任务/素材/作业/版本）、`creator_routes.py`（原会话鉴权外加同源检查/流式上传）、`frontend/src/CreatorWorkspace.tsx`（步骤/保存/上传/播放/回填）、`creator-api.ts`（带认证请求）、`AppShell.tsx`（现有模块切换）。

## 已执行验证与自查

- 自动检查共100项：43前端、23基础API、8图片、12画布、6编排、7创作/真实视频、1安装。既有文件边界和SQLite重开通过；tsc/Vite通过。
- 前端真实组件检查：未保存内容时禁止合成/上传/切换；回填只生成草稿；轮询不覆盖未保存稿件，隐藏模块停止轮询；旧成片不允许打包，历史下载需明确选择并带认证。
- 真正API联调：上传自制封面/视频、同版SRT/JSON，实际后台合成7.2秒、720×1280、H.264、有声音的成片。输入hash全部未变，认证下载字节相等，无凭据与跨来源请求拒绝。
- 浏览器：任务五步就绪、同一素材/稿件恢复；视频readyState=4、尺寸720×1280、时长7.2秒，实际播放至ended。回填Chat草稿没有发送，联调草稿清理；替换封面后仅包过期，重建包恢复就绪。新文件选择器及二进制上传实际通过。
- 自查修复：上游CORS控制响应可见性，不等于拒绝带有效token的跨来源HTTP请求；新创作接口显式检查Origin，真实API复测拒绝。轮询只接受不低于当前revision的返回；历史文件按需下载，避免预先加载全部媒体。回填显式指定口播Skill，避免沿用之前的动效Skill。

执行命令：`.\scripts\miniclaw.ps1 test`、`.\scripts\miniclaw.ps1 build`。服务已运行时可执行`.\.venv\Scripts\python.exe scripts/verify_creator_flow.py`，它会生成自制样片并创建验收任务，不调用模型/百炼/平台。本机样片使用Windows Huihui合成语音，SRT时间按实际WAV片段长度计算，不凭文案猜时间；该脚本不代表应用已经接入TTS。

已有样片之后用`.\.venv\Scripts\python.exe scripts/verify_creator_flow.py --resume`仅复核原任务及当前包，不新增任务/转码/合成语音。准确服务重启后此命令已通过，当前素材、成片、新版包与五步就绪恢复。

证据在被Git忽略的`.codex/verification/creator-flow/`：`report.json`、`video.mp4`、`publish-package.zip`、`creator-workspace-ui.png`。无第三方平台素材复制。

## 用户后续验收

1. 从侧栏打开“创作工作台”，选择“验收样片 · 虚构陶瓷杯”，播放与下载已有技术样片。
2. 新建自己的任务，保存真实商品事实；带入Chat，确认显示口播优化Skill，主动发送，复制主稿回任务保存。
3. 从图片工作区导出封面并上传，上传自己录制的短视频/对应SRT/编排JSON，合成、播放并核对声音、中文、挡脸与首尾。
4. 只替换封面，预期成片仍有效、包过期；换视频/SRT或比例，预期成片过期。
5. 刷新、模块往返、后端重启，预期已保存任务、历史输出和状态可恢复。未保存输入需先点保存，当前不承诺刷新保留未保存的表单。

本轮没有真人素材质量、移动端实际OS下载、平台发布或账号收益的验收证据。手机窄视口的入口、表单、成片与包已查看；大屏浏览器布局尚未单独验收。
