# 本地文件存储与正式版本验收

日期：2026-10-08。范围：本地存储规范、集中 schema、存量迁移、版本重用、OSS 后端协议。Chat 附件上传 UI/分片与 OSS 实际接入延期。

## 实现与验证

- 业务库集中兼容 DDL 与校验迁移：31 表，原23表记录保留。Hermes state.db schema 未改。
- 新媒体不可变 SHA256 对象；流式写入、去重、原子发布；可配置本地根目录与可注入云适配器。本地读取 Range/206、鉴权和 Origin 校验。
- 正式版本独立于快捷撤销；父版本链、当前指针、固定对象引用。恢复再编辑保留后续分支，节点位置变化不创建媒体版本。
- “基于此版继续”应用候选到精修工作底图，保留原画布采用状态；正式图层恢复初始化一次，后续编辑不被旧版本覆盖。仅 file 的旧版本单独建立工作底图，不覆盖旧图层文档。
- 旧视频需显式历史采用；当前输入不会被改成旧输入，未显式采用 stale 结果仍拒绝；新成片保存实际采用版本清单。
- 项目资料→版本包含图片、文案和视频结果。实际窄屏进入列表、缩略图加载、筛选可用；移除节点的历史不伪装成当前可恢复节点。精修历史保留正式文档版本。

测试：Python 98 项通过；Vitest 27 文件/167 项通过；TypeScript 与 Vite 构建通过。底层用 201 MiB 流式对象验证分块读写和去重；内存云适配器验证缓存校验；二进制图片接口验证401/403/206；CAS、跨项目版本拒绝、精确幂等重放、分支像素导出、迁移重复执行均有测试。未调用付费生成或真实 OSS，没有验证 Chat 断点续传。

## 实际迁移

- 备份：`.hermes/backups/storage-20261008-150216-174700/`，两个数据库 backup API 副本及旧文件hash清单；旧媒体原位保留，备份目录不是完整媒体异地副本。
- 数据库：750,260,224→6,729,728 字节，715.5→6.4 MiB。减少数据库重复 Base64；不声称磁盘总量同比降低。
- 23工作区、370回执、196撤销快照保留；72对象、533正式版本。原23表记录数量一致。
- 与迁移前库核对：工作区状态仅规范化媒体引用；回执签名、历史响应与revision一致；撤销快照仅新增 version_id；72对象逐字节hash验证。生成状态/task_id和Chat消息/会话数量保留。
- integrity_check=ok，foreign_key_check无异常，warnings为空。保持DELETE journal，离线备份后VACUUM；没有删除旧媒体/历史或重发云任务。

## 限制

旧版本仅有file时只能重用像素；已被旧撤销删除的分支不可恢复。正式历史/旧媒体暂不自动GC，也无历史配额。当前为单机个人工作台，多用户云部署需补身份隔离。OSS接口不等于SDK/配置已启用。Chat上传限制与整包协议仍保留；固定消息revision、分片、outbox单独实施。
