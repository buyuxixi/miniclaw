# 第八步：创作工作台 UI 返工

日期：2026-10-03。用户已拒绝上一版大表单界面；本轮重新设计，效果待用户验收。

## 实现流程

把内容、口播、视觉、视频、导出分为五个可切换步骤；左侧作品库，中央当前步骤，右侧固定作品预览。事实、稿件和发布文案分步编辑，来源记录折叠，保存状态明确。生成、取消、回传冲突和历史产物仍使用真实后端状态，没有模拟进度条。

实际读取 mono-color 的设计指南与颜色目录，选择 `substrate_neutral_white` #FAFAF7 和 `palette_mint_charcoal`：#5EB783 强调活动步骤，#302D2E 承载标题和正文。运用现代编辑分栏、尺度层级、受控强调和留白；海报的印刷网点等约束没有硬套在操作控件上。国风标题和器物构图用于作品本身，工作台保持可读的现代工具界面。

入口：`CreatorWorkspace.tsx`、`creator.css`。桌面为作品库+编辑+预览；较窄窗口把预览放在编辑区域之后；手机作品库横向滚动、五步骤保留一行。回传使用原生 modal dialog，确认前保留旧项目数据。

## 验证与 review

TypeScript/Vite 构建及前端46项检查通过。真实浏览器检查1280×900桌面、390×844手机、恢复后的319×672侧栏。手机 body 的 clientWidth/scrollWidth 均390，侧栏均319，没有页面级横向溢出；作品库允许在自己的区域内横向滚动。手机预览位于表单之后。桌面真实最终截图 `outputs/tea-film-v2/workspace-final-desktop.png`，手机截图 `workspace-final-mobile.png`、`workspace-mobile-preview.png`。

Review 修复了首帧淡入导致预览黑屏的问题：播放器使用本项目实际封面作为 poster。旧失败任务保留在折叠历史中，当前成功状态单独显示；顶部导航保持可见。回传确认使用原生 dialog，关闭与放弃不改项目。桌面截图的项目已保存为v11，五步产物均就绪。

## 用户验收

1. 打开“留一刻，给茶 · 国风口播短片”项目，在五个步骤切换，确认能看到当前封面或视频，而不是长表单中寻找输出。
2. 编辑但不保存，切换步骤后检查内容仍在；切换作品应被阻止并提示先保存。
3. 分别在宽窗口和窄侧栏使用，检查文字、按钮、上传区域不横向溢出，预览和下载可用。
4. 打开回传对话框，检查预览、编辑、放弃、确认和 Esc 关闭。

没有将“颜色更好看”视作全部验收：实际作品质量、模块往返和自己的创作素材仍是验收重点。
