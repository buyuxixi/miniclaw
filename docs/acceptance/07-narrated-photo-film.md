# 第七步：图片、主稿、配音与视频直接合成

日期：2026-10-03。实现完成，真实约19秒样片通过技术验证，用户审美验收待定。

## 实现流程

项目选择“图片口播短片”，使用封面、材质特写、场景图片和已保存主稿。点击“合成视频”才将主稿发送到已配置的北京地域百炼 Qwen3-TTS-Flash / Cherry；没有第二套 Key，不自动重试。缺少 Key 时明确不可用，不以系统朗读冒充云端配音。

主稿限制为320字、1–12句，每句最多36字。每句返回独立音频，按实际 PCM 字节数测量时长，并规范化为有效 WAV。已确认真实服务可返回流式占位 WAV 头，因此不能直接相信 header 的巨大 nframes。字幕边界取实际句音频长度，包含开场留白和句间停顿；这不是逐字 ASR 对齐。

原创固定镜头配方：封面开场、特写与场景交替、封面收尾，缓慢推进、短淡入淡出、下方字幕。FFmpeg 使用 argv、固定文件名和 `textfile/expansion=none`，稿件不能成为 shell 或滤镜指令。输入图片原件保留。输出竖版1080×1920或横版1920×1080、30fps、H264/AAC，生成的同版 SRT 随发布包导出。

原有“视频+SRT+文字动效”和“视频+透明MOV”模式保留。一个串行队列仍统一处理任务、取消、失败、重启与不可变产物；改稿或换图会让图片口播模式的旧成片失效。

Review 后增加统一音量处理（目标 -18 LUFS / -2 dBTP）及同项目逐句配音复用。只复用已完成的本项目产物中相同模型、音色、正文对应的音频，保留原请求记录并标记 reused；改变正文则生成新句音频。图片口播预留512 MiB任务预算，控制编码码率，防止中间音频、镜头和成片突破存储预算。

## 素材和 Skill

`outputs/tea-film-v2/` 保存三张原创 imagegen 素材及提示词记录。使用用户提供的 chinese-style-poster-skill：D05器物广告、D03材质特写、D08哲学留白，F09清雅标题、L02横向标题，按青瓷釉色与器物圆口组织构图。没有搬运短视频平台视频。

这是原创 AI 视觉概念样片，不宣称真实商品品牌、尺寸、价格、功效或消费体验。Chat 审稿时删除“杯口有一点点温”的无依据暗示，采用六句主稿。

## 验证与 review

- `tests/test_storyboard.py` 实际 FFmpeg 输出1080p、音轨、三种镜头与 SRT；覆盖流式占位 WAV 头、图片归属、CAS、URL域名和稿件上限。
- 百炼下载只允许固定 OSS 结果域名，升级 HTTPS，不跟随跳转，最大8 MiB/句；不接受用户任意 URL，错误信息不回显 Key 或签名 URL。
- 实际服务首次合成发现 WAV 头兼容问题，失败记录保留，按 PCM 长度修复后复验。
- `scripts/verify_creator_quality.py` 默认只准备/恢复素材；`--render` 明确发起一次合成，`--collect` 只收集已完成作品与发布包。

## 用户验收

1. 保存六句主稿，添加封面、特写、场景图，视频步骤选择图片口播模式。
2. 点击合成，等待完成并播放，核对音量、断句、字幕内容、镜头和中文标题。
3. 改一句主稿并保存，检查旧成片不能作为当前发布包。重新合成后生成发布包，解压检查 MP4、同版 SRT、封面和文案。
4. 再用自己的图片和主稿重复一次；不能用本样片成功代替真实素材验收。

## 明确限制

本次样片是三张原创 AI 图片的动态剪辑，不是实拍视频、人物数字人口型或扩散模型视频生成。暂不加自动找商品、多 Agent、平台发布、长视频时间线或背景音乐版权管理。用户自己发布。取消云端请求时最多等待当前 HTTP 请求的超时，已发出的请求可能计费；后续句子不会继续请求。

最终文件与发布包逐字节/hash核对通过：1080×1920、30fps、H264 yuv420p、AAC双声道48kHz。视频流19.088秒、含音频的容器19.160秒，均为约19秒；6条字幕来自同版生成文件。对最终音轨测量 integrated -18.57 LUFS、true peak -3.83 dBTP；这是客观响度检查，不替代个人试听。最终调整复用6句已完成音频，没有再次调用配音接口。详细来源和验收见[返工总报告](09-quality-review.md)。

百炼官方接口：[Qwen-TTS API](https://www.alibabacloud.com/help/zh/model-studio/qwen-tts-api)。设计来源：[国风 Skill](https://github.com/dacnay816y62-hub/chinese-poster-skill)。
