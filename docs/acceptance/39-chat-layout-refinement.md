# 节点操作合并与 Chat 布局精修

2026-10-08，使用 oil-ui-pro。意图为已有 UI 升级与节点动作承载修正；保留品牌、全局导航、已有任务和对话功能。

## 方向与边界

工作台 Chat 以输入与阅读为主：浅灰侧栏、白色正文、有限的阅读宽度，空对话输入区居中，有内容后输入区停在底部。品牌字标保留，节点画布继续深色。颜色一致不能代替聊天的布局与操作层级。

用户提供的四张当前截图作为前态基线。官方豆包 Chat 与 DeepSeek 页面已尝试访问，但本次外部页面无法取得完整可交互画面；不声称完成它们的逐像素复刻。本轮以用户的明确问题和常见聊天操作结构为依据。

## 实际调整

- 图片生成、图片编辑、视频生成的删除动作进入各自编辑面板。图片编辑合并完整编辑、生成视频、下载；视频保留导演讨论、完整编辑、核对采用和结果再次生成入口。多选与备注继续使用上下文工具条。
- 隐藏只有删除动作的浮动工具条；点击空白关闭浮层，重新选择仍保留提示词草稿。
- 项目资料的关闭、镜头定位与打开 Chat，以及节点底部入口和编辑动作使用固定几何的 SVG 图标。
- 侧栏移除新建/搜索的厚边框，收紧导航与对话行；消息使用克制的用户气泡和普通回答排版。复制与复用保留可访问名称和提示，工具调用由大卡片改为紧凑可展开记录。
- 去掉用户消息上方重复的“你”、回答中重复的品牌名称和复制/复用的常驻说明；输入提示改为“输入消息…”。保留工具失败、完成、停止与未加载状态，未知状态不改成成功。没有参数时不渲染空参数区。
