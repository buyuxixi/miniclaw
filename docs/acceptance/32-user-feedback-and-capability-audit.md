## 统一任务路径与学习重点

首页展示任务和半成品，任务内固定提供修图、口播、视频入口。每个入口使用同一Chat提出要求，旁侧展示本轮工作产物与当前采用版本。方向资料作为共享上下文，不强迫每轮重新填表；节点可以来回修改。

一个任务允许多次对话，每次都应恢复所属任务和当前产物。保留普通Chat用于学习与自由讨论，显式创建或关联任务，不能把自由聊天自动绑定成商品项目。

学习重点是主Hermes agent如何读取本轮上下文、选择Skill、调用Tool、保存产物版本。UI把这个过程显示清楚，内部ID与工具参数折叠到详情。本阶段复用既有执行能力，不另建通用Flow引擎。

验收路径：打开半成品→Chat提出改图要求→直接预览该方案→执行或生成候选→比较并继续改→采用→切到口播改稿→刷新与重新打开。基础任务不要求用户复制提示词、猜目录、找第二个Chat或理解蒙版与revision。视频未贯通前不呈现为完整可用流程。
