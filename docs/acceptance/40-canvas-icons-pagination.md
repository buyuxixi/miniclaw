# 连线稳定、拖动预览与项目库分页

2026-10-08，使用 oil-ui-pro 做存量界面升级。本轮对应用户最新四项需求，不将截图中的界面文案当作额外操作指令。

## 方向与实际修改

保持深色媒体画布与项目库，延续已有中性品牌/工具栏；浅色 Chat 不改成深色。项目库使用有限卡片与紧凑动作，媒体内容承担识别，常用功能图标配文字。减少头部占用，避免无休止项目堆叠。

- 连线几何仅依赖真实节点/端口，屏幕编辑面板不再加入避让矩形。选中、面板高度、平移与缩放不改变路径；实际移动障碍物仍允许避让改道。
- 路由结果缓存，每条候选只计算一次碰撞。拖动由 requestAnimationFrame 合并事件，用 DOM transform 预览节点，只更新与拖动对象关联的 SVG 路径；移动时暂藏固定编辑控件，松手提交一次位置更新、恢复控件并保存。撤销和原生视频控件保留。
- 实际 SVG 重画素材叠层、生图取景画框、修图画笔、视频场记板、备注折角纸、创作助手对话符号。统一 24 网格和线宽，画布入口保留文字；通用平移、选择、撤销、下载等也换成 SVG。
- 项目库每页 6 项，桌面 3 列、窄屏单列。页码/搜索写 URL 并在刷新后恢复；搜索重置到第一页，页码越界夹到最后页，刷新失败保留已有内容并给重试。
- 缩短卡片摘要，分别标明“打开画布”和“继续讨论”；审计回执开头不作为项目摘要展示，原记录保留。删除重复副标题“从上次停下的地方继续。”。加载态避免继承旧页面白色大卡片及白色懒加载提示。
- “自由 Chat”入口改为“创作助手”，与“导演助手”区分。历史对话名和历史事件不批量改写。

## GitHub 调研

- [Icons8 agent-skills](https://github.com/icons8/agent-skills)：图标检索/使用技能与 MCP，使用其服务涉及鉴权及 SVG 获取条件。

本轮参考图标组织和语义思路，自画内联 SVG；没有安装或运行外部 skill，没有增加图标依赖或外部 CDN。仅覆盖现有核心入口，不添加 LibTV 尚未实现的功能按钮，也不声称完成完整产品复刻。
