# 第二十三步：创作者导航与图片方案

日期2026-10-04。用户授权大胆优化流程与图片表现。实现状态、开发者试跑和用户体验验收分别记录。

## 已完成与使用入口

创作工作台默认“依据→图片→口播”，显示当前项目下一步；作品库、手动资料折叠，视频放到进阶区。上传原图后可只写一句目标，点击“和Chat确定创作方向”；原图与项目进入Chat草稿，由用户发送。建议通过“采用为创作依据”预览、修改和确认，无需先填五栏，但仍须核对事实。

图片节点提供留白画册、暗调展陈和AI摄影精修。截图仍须先在原生画布裁去购物界面，本轮正式项目沿用已保存裁剪。构图先看真实前后PNG，确认才写画布；4:5原照片完整等比适配，标题、图片、线条可编辑、可撤销。采用封面回传后提醒核对口播，符合新图可明确保留旧稿。

沿用单主Chat、共享依据和节点工作区。没有通用Flow/多Agent系统、Blender安装/建模，没有外部Codex制图代替工作台，也没有新增配音/视频/发布。

## 实现与检查

七个原生CanvasDocument图层。preview接口按当前项目素材归属、revision与文档校验，真实Pillow渲染PNG，不写文档/历史/选区；应用需冻结版本匹配。重复构图/精修复用原照片层，避免标题再重绘。精修导出当前可见画面，避免发送裁剪前整张手机截图。跨商品重置标题，同项目轮询保留输入；繁忙期间延后消费导入，结束后继续。

- 前端八文件50项通过，含原图直接进入Chat、三步/进阶入口、预览先于保存、跨商品隔离和旧采用/续作回归。
- Canvas后端13项通过，含真实像素、预览不持久化、旧revision/跨项目素材拒绝；原生preview POST和PNG实际使用。
- Basic API26项断言通过、退出0，但退出有既有异步gateway占用测试临时SQLite文件的清理异常；不能写全部日志无异常。
- TypeScript/Vite生产构建通过。新增跨商品恢复曾误写type字段被构建发现，按真实schema改kind后重建和50项检查通过。
- 原生浏览器1440×900/320×672核对导航、入口、图文布局，恢复原尺寸。普通用户独立完成率和耗时尚未测量。

## 质量判断与Blender

沿用第二十一步评价体系：事实/购买理由/证据、图片、口播、统一性、交付分别检查，不因换版式抬高总分。细节改错是图片不通过项。两图可作外观展示候选，仍有高光、缺乏真实特写/场景，不能证明材质工艺容量性能；稿件是审美选择介绍，尚非完整商品证据的强销售稿。

后续优先：缩短Chat建议、按部件核对、截图裁剪引导、前后图轮廓/颜色/部件/纹理核对提示，补真实规格和使用场景，再确定购买理由与视频镜头。通过创作者独立试跑验证收益。

Blender有Cycles灯光/材质/景深，并支持后台调用，官方参考：[Rendering](https://www.blender.org/features/rendering/)、[命令行参数](https://docs.blender.org/manual/en/5.0/advanced/command_line/arguments.html)。可作为未来主Agent调用的可选渲染工具，有可信模型或多视角资料后提供摄影棚/机位/灯光模板。两截图不构成可信背面、几何或材质；PATH/常见目录未发现安装，本轮没有安装或运行Blender，不能声称验证三维渲染，也不应要求普通创作者学习建模。
