日期：2026-10-09。用户已做好版本管理并授权按 Claude 方案 B 编码；使用 oil-ui-pro 0.17.0。实现与本地验证完成，视觉等待用户体验反馈。

## 交付行为

- `/` 以通用 Chat 为入口，旧模块缓存不再把首页带到 Creator。`/c/:session` 打开指定对话，`/p/:workspace` 打开画布，`/projects` 打开项目列表；原查询参数链接仍可读。
- 画布助手顶部保留唯一“完整对话”入口，指向项目已经关联的 Hermes 会话。实际走通“助手 → 完整对话 → 打开画布”，历史内容与项目一致。没有迁移会话或修改数据库结构。
- 对话和画布使用共享设计变量。侧栏识别关联项目，保留用户自定义标题；项目列表返回时保留已挂载 Chat 与草稿。
- 节点编辑默认显示两行摘要，展开后编辑。选中节点不自动移动视野，展开时才按遮挡调整；正常手机高度下将当前节点预览滚到编辑器上方。
- 底部创作和视图工具合并，手机隐藏不适用于纵向列表的空间控制；节点名称与创意摘要更易读。原文件名和 Markdown 原文保留。
- 模型菜单保持贴近触发按钮，根据空间翻转与滚动。项目资料、图片模型菜单、视频模型菜单均以实际项目检查。
- 画布脚本格式化为可阅读源码，将多处 `window.film` 替换链改为一处显式装配；删除被后层覆盖的重复方法。composer/workbench 样式并入 `style.css`，共享颜色进入 `tokens.css`。未把整个应用迁移到新的前端框架。
