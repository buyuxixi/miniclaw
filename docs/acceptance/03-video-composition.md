# 第三步验收报告：本机视频合成

日期：2026-10-03。状态：实现完成、开发者验证通过、用户真实口播验收待做。前序见[字幕编排](../video-overlay.md)，总进度见[进度表](../project-progress.md)。

## 实现流程

文件上传与任务归属 → 本机FFprobe读取视频真实元数据 → 对JSON重新按同版SRT编译，或核对透明MOV → 原创Pillow文字卡/FFmpeg透明合成 → H.264/AAC MP4 → 探测结果并发布不可变版本。全程本机执行，无新增Agent、模型媒体上传或云端费用。

核心代码为`miniclaw_web/video.py`，入口为创作工作台的“合成视频”。720×1280竖版和1280×720横版均保留完整输入画面，等比缩放并加黑边；竖版JSON文字卡重新布局，不拉伸外部横版卡。短重点/金句/多行卡采用本项目原创简洁文字框与淡入淡出，视觉与Overlay工作台不同；本轮多行卡不复刻外部动态重排。外部透明MOV仅横版16:9，需有真实alpha。

原音轨只取原视频第一条音轨，转AAC；无音轨视频可正常合成，程序不凭空配音。输出30fps，时间零点归一化，保留视频时长。透明层结束后`eof_action=pass/repeatlast=0`交回原画面；显式映射音轨和faststart用于成片，依据[FFmpeg过滤器文档](https://ffmpeg.org/ffmpeg-filters.html)和[FFmpeg输出文档](https://www.ffmpeg.org/ffmpeg.html)。

## 环境与边界

需要本机FFmpeg、FFprobe和中文字体；缺失时创作工作台提示原因，Chat/修图继续可用。按优先级查`MINICLAW_FFMPEG`、`MINICLAW_FFPROBE`、PATH，本机已有私有工具目录作为最后回退。中文字体支持`MINICLAW_VIDEO_FONT`，Windows回退微软雅黑、Linux回退Noto CJK。工具和字体不打包到Git。

在其他电脑准备好工具后，可在启动服务的同一终端配置（路径按实际安装修改）：

```powershell
$env:MINICLAW_FFMPEG = 'C:\Tools\ffmpeg\bin\ffmpeg.exe'
$env:MINICLAW_FFPROBE = 'C:\Tools\ffmpeg\bin\ffprobe.exe'
$env:MINICLAW_VIDEO_FONT = 'C:\Windows\Fonts\msyh.ttc'
.\scripts\miniclaw.ps1 web
```

本机已准备工具；干净克隆不带这些运行时，也不需要启动外部Overlay才能渲染本项目的JSON文字卡。

支持MP4/MOV/WebM，单文件最大256 MiB，0.5–180秒，最多3840×2160像素；字幕/JSON 64 KiB、封面5 MiB。拒绝URL/播放列表/未知容器，进程使用参数数组、限定文件协议与容器，不运行shell。新工具不会授予Chat任意命令权限。转码限600秒，可取消；重启标失败，不自动重放。服务仍是本机单profile。

## 已执行验证

运行`.\.venv\Scripts\python.exe tests/test_creator.py`，七项通过，包含真正FFmpeg执行而非模拟视频渲染：

1. 自制360×640、6秒/30fps测试图案＋440Hz测试音，经真实JSON/SRT合成720×1280 MP4；时长误差不超过0.08秒、存在音轨，解码重点卡像素为蓝色。原素材hash未变。
2. 自制2秒透明MOV覆盖6秒原视频，首段解码可见红色测试框，4秒帧该位置回到黑边；输出仍为6秒且有音轨。
3. JSON改时间、加功效/偏移/未知字段拒绝；字幕与编排必须同版。
4. 真正启动编码器后取消，受控子进程5秒内结束。排队取消和重启失败不产生公开成片。
5. 非UTF-8、伪图片、播放列表、跨任务文件、过期revision、大文件拒绝。
6. 成片与发布包跨服务实例恢复，输入比例改变后旧成片标过期。
7. 音轨原始延迟0.6秒的真实视频，经合成后前0.2秒仍静音、0.8–1秒存在测试音，保留相对画面偏移。

自查后优化：素材魔数/容器白名单、透明通道精确识别、字幕二次编译、错误日志留本机但API不暴露进程内容。第一轮透明层测试素材因FFmpeg drawbox保留原alpha而全透明，定位后改用有已知RGBA像素的自制PNG编码MOV，保留像素断言后通过；没有削弱合成检查。

## 用户后续验收步骤

1. 进入“创作工作台”，新建任务，保存比例和合成方式；上传自己的原视频、同版SRT和Chat生成的JSON。
2. 合成后播放与下载MP4，核对中文、人物是否被挡、完整画面、首尾、声音与字幕。若选外部透明MOV，先选横版。
3. 替换字幕或视频，预期旧成片提示过期；重做保留旧版本文件。
4. 运行中取消，预期显示已取消；重启服务，未完成任务显示失败，可手动重做。

测试音不是真人口播。没有据技术样片宣称真人音画同步、口播自然程度、长视频性能或平台接受性通过。
