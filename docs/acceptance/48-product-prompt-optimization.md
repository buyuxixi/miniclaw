# 产品宣传提示词优化 · 2026-10-08

用户任务：把普通的修改要求整理成可直接用于商品修图和视频生成的专业提示词，先比较再采用，减少重复请求。

## 完成范围

- 新增 `skills/product-prompt-optimize/SKILL.md`，已通过现有认证 API 安装到应用的 creative 分类并登记空工具依赖；设置中归入策划与文案。prepare 沿用同一分类路径，不安装第二份，也不替换用户自定义内容。
- 共同业务场景是产品宣传，明确区分 image-edit、image-generate、video。技能要求保留包装身份与文字、重写冲突句；修图写变化而非重画外观，视频写运动方向、幅度和时间过程。背景调暗和产品倾斜的实际图像效果当时没有收费验证；用户后续报告的出图失败及规则修正见验收49。无真实视觉能力时不声称读图。
- 图片采用严格 product-prompt 格式，视频沿用单镜头 studio-plan。仅生成文本建议，采用只保存文字，用户另行点击生成；不自动调用修图/视频工具，不在失败时重发收费任务。
- 修图与生图节点在原有字段标题旁增加一个低强调优化入口，复用导演优化比较区。先查看新提示词/原提示词，确认后返回原节点；模型身份和文字优化的范围用一行说明。长修改说明折叠，仅显示第一句/短摘要。
- 当前实际文字优化模型是 deepseek-flash，供应商是 DeepSeek；百炼 Qwen Image 用于图像编辑。配置与真实 iframe 界面均核实，没有改供应商。
- 优化请求跳过额外的 Jev 影子操作分类；用一轮聊天请求处理文字。Agent 底层可能有多次模型调用，不能把一次点击硬说成供应商恰好一次 API 请求。
- 已完成建议保存回复编号、所属对话、对象与原文字基准；关闭后重新打开直接恢复，避免重复优化。采用时检查当前图文件及提示词；失败保留草稿，成功重试通过现有项目保存幂等机制处理，不覆盖新的手动改动。
- 新后端运行时避免给纯提示词优化自动建立精修上下文。当前旧进程无需新接口或重启即可使用主要流程：技能动态安装、现有聊天提交和项目保存均已验证。
