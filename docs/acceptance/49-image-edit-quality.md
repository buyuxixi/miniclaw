# 修图质量失败调查 · 2026-10-08

用户反馈：优化后提示词使商品图背景和包装出现大量彩色颗粒，倾斜也未达到要求。

## 已确认的证据

- SQLite 只读查询最近任务：同一源图 `7110922ef8904a7a9440750e93573d18`、同一313字提示词，先后调用 `qwen-image-2.0`、`qwen-image-2.0-pro`，均由 DashScope 返回成功。Pro任务 `a222f56d74276751372de4e5016fd199` 的保存结果与截图噪点效果相符。
- 直接查看不可变源文件与Pro候选文件：源图是平滑绿色背景，候选背景及包装有明显颗粒；问题存在于图片文件，不是浏览器缩放或展示。
- 两任务均为整图编辑，region=false、visible_only=false、feather=0，遮罩全部255。代码发送源图和保存提示词，关闭供应商 prompt_extend；结果转换PNG并按源尺寸缩放，然后全白遮罩合成。代码未添加噪声或纹理滤镜。
- 原始供应商下载字节没有单独保留，因此无法逐字节对比云端原始输出与应用落盘结果。结合处理代码，颗粒来自生成阶段是推断；没有做收费对照实验，不能认定提示词或模型是唯一原因。
- 提示词反复罗列否定纹理，姿态改变与“商品位置关系保持不动”存在冲突。文字优化请求不携带图片像素，不能声称判断了当前产品倾角。

## 本次修正

- 更新产品提示词技能：简单修图目标60–140字、最多180字；用3–4句写动作和程度，保留包装一句即可。正向描述目标，删除失败材质清单；允许姿态变化对应的轮廓位置、投影变化。
- 明确向左倾斜是顶部朝画面左侧，区分最终角度与增量；有实质歧义先问，不凭空判断原姿态。
- 图片优化请求同步这些要求。解析器2000字兼容上限保持，避免旧建议突然不可读取；180字是新优化指令要求，并非自动裁剪。已有建议缓存仍可查看，不自动重新调用模型；新一轮优化使用新规则。
- 经内容hash检查，通过认证API更新应用现有技能及空工具绑定，实际读回内容一致且绑定current。原技能备份保留。未修改原图片、候选、工作区或任务，不生成任何新媒体，也未新增收费文本请求。
