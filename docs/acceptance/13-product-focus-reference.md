## 下一版建议（依据用户要求，非BUV参考观察结论）

先做15–20秒产品表现短片，继续沿用同一创作项目，不为了提高视觉质量增加多Agent或通用Flow。

1. 产品镜头为主，建议占画面时长约70–80%，人物仅用于短暂使用情境。这是本轮建议比例，不是参考片统计。
2. 开头优先杯体/杯沿的明确产品展示；中段用材质微距、玻璃与茶汤细节、产品使用；收尾做干净的产品定格与信息层级。
3. 让光线/反射/透明材质细节被看见；若要新增光影拍摄或图生视频，先准备能锁定同一产品外形的素材，避免在不同镜头改变杯口、杯型或材质。现有FFmpeg调色不能创造真实缺失的摄影细节，新增生成能力需实际试验后记录，不能宣传成已实现。
4. 特效依附产品：强调杯沿、液体与局部信息，按镜头目的使用遮罩/跟踪或少量文字；不以无关粒子/转场数量作为品质标准。不能做没有事实支持的材质、保温、功效或性能演示。
5. 旁白每句对应一个产品信息/画面动作，减少泛情绪句；音乐和音效配合动作，保留足够产品观看时间。
