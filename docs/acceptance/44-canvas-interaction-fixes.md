- 费用记录全部无法估算时显示“待估算”，避免用 ¥0.00 表达未知。历史缺失参数不会填造扣费。

## 使用示例

选中“泥膜质地特写”的镜头或结果 → 优化提示词 → 填写“产品与包装保持不动，绿色泥膜持续缓慢流动，表面隆起再摊开，起伏和流向清晰可见，固定相机，保留包装文字” → 优化并预览 → 比较并采用 → 生成新视频。

原提示词同时含 rigid/stationary、泥膜完全静止，只追加“流动感强烈一点”会形成相互冲突的要求。新入口要求重写冲突部分。用户原提示词与既有视频未自动改写。
