## 后续统一验收顺序

1. 新建 Chat，验证发送、多轮、停止、刷新与重新连接。
2. 上传自己的商品图，做一次本地修图，核对原图与版本，再自行决定是否试一次云端编辑（可能计费）。
3. 在画布增加中文标题，做选区与撤销，导出并确认文件能在本机打开。
4. 用同一商品事实运行封面设计 Skill，比较实际色值、标题与布局；用真实原稿运行口播优化，朗读一次并检查未验证宣称。
5. 在同一项目采用Chat主稿与画布封面：图片素材用“图片口播短片”；已剪好的实拍视频用“镜头片口播”，选择声音、决定替换原声或保留背景音，再生成配音/字幕/1080p成片。已有视频也可用同版SRT/动效JSON或外部透明MOV合成。
