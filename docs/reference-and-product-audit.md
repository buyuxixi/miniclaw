# 修图参考覆盖与产品体验复核

2026-10-04。此表保留第二十六步实施前的审计基线。用户随后授权有用能力全面适配，已补14种方案动作、有限多步预览/应用及选区主体背景拆层，最新实现与证据见[第二十六步](acceptance/26-image-plans-and-subject-layers.md)。其余缺口继续适配，不声称已完整迁移所有能力。审查固定源码版本，未复核上游最新版本。

## 结论

不能回答“提供的项目都充分用上了”。主修图项目的基础编辑、画布、选区、候选和自然语言工具调用已经借鉴；完整的多步修改计划、自动拆层、专门的扩图/超分和批量输出尚未完整适配。设计 Skill、修图应用、口播动效应用也不能作为同一种能力统计。

近几轮补了方向采用、续作恢复、截图裁剪和放大核对。这些解决具体障碍，但没有充分解决“说目标后怎样得到一张好图”的整体体验。新增控件和工程测试通过不能据此给图片审美或普通用户体验加分。

## 主修图项目：关键能力逐项比较

| 参考能力 | 本工作台现状 | 对用户的实际影响与安排 |
|---|---|---|
| 自然语言改图 | 已有Chat与原生编辑工具；摄影要求仍可表现为长提示词 | 不应要求用户自己写专业参数、复制模型建议；优先补目标到修改方案的直接回传 |
| 多步计划与确认、依赖、重试 | 有任务状态、版本和预览；没有统一的可执行图片修改计划 | 用户难判断会改什么、先后怎样、失败从哪里继续；下一阶段优先补轻量方案，不引入通用Flow引擎 |
| 图层、变换、选区、历史 | 已实现；矩形/套索/画笔及SAM点选有本机验证 | 保留能力，默认隐藏操作细节，需要精调时再展开 |
| 局部调整、擦除、AI区域编辑 | 已实现并有区域边界验证 | 选区仍常由用户管理；后续让目标对象与范围选择更直接 |
| 主体/背景/文字自动拆层、对象提升与背景补全 | 有SAM选区和提取，未完成整套自动拆层管线 | “提取选区”不能宣称一键自动拆层；商品保真换背景需要单独设计和测试 |
| 换背景 | 通用AI编辑可以提出此要求，现有区域合成可保护范围 | 不是已验证的一键商品保真换背景；整图精修实际改错过纹理和绳线，不能只加强提示词 |
| 扩图、超分 | 有画布尺寸调整和普通像素缩放 | 不等于模型语义扩图或细节超分；列为独立能力，不能复用名称宣称完成 |
| 多候选与比较 | 有候选/采用/拒绝、版本记录和放大对照 | 没有与原项目等价的完整多候选生成墙；先确保一个候选能看清、拒绝后能准确续改 |
| 营销图、多尺寸和批量处理 | 有两种可编辑4:5构图及单项目导出 | 尚非批量营销输出；在单商品流程和质量通过前不优先扩张 |
| 无源图文生图 | 当前原生百炼图片编辑需要源图 | 没有通用文生图能力；本阶段用户原素材流程不依赖它 |

## 产品应当怎样超越参考

参考项目主要解决图片编辑，我们要解决同一商品从原素材、创作方向、展示图到口播的连续创作。价值在于少解释、少搬运、可继续、能交付。

建议默认路径：**上传原图 → 说本次用途和想改的地方 → 看Chat修改方案 → 预览/生成 → 比较并继续改 → 采用 → 同依据打磨口播**。可以反复回到图片节点，修改不应迫使用户重做商品资料或口播。视频仍是后续阶段。

“去截图界面”“调整光线”“保留商品换背景”“做展示封面”可以作为目标提示，但目标必须匹配实际能力。尚未实现或容易改错的目标应解释范围、提供可行替代，不展示成已可一键完成。

用户看见的是当前工作图、想改什么、哪些必须保留、会执行哪些动作、结果是否满意。图层、蒙版、模型参数、工具名称放到精调或诊断入口。当前已有的五项创作依据继续作为共享数据，用户可纠正；不要求每轮先填五个表单。

## 接下来按收益排序

1. **优先完成Chat与当前图的直接协作。** 修改要求和方案绑定当前项目/版本，Chat建议可直接带回要求；先看方案再执行，结果支持“保留商品，只把背景再暗一点”这样的连续修改。复用同一个主Agent和现有画布，避免新建独立修图Agent。
2. **其次补商品保真与摄影质量。** 先解决区域保护与明确改动范围，再优化布光、背景、接触阴影、反光和构图。整图精修不能因为画面更漂亮就采用；失真时保留原图并明确失败，不把人工四项勾选称为自动质检。
3. **然后补可直接交付与少量风格方案。** 一个明确买点配一套视觉方向，展示整体/细节与对应口播；从真实合格成果沉淀可编辑模板，再扩展多尺寸/批量。国风和单双色方法应产生用户能比较的实际作品，而不是一段更长的提示词。

## 两套验收：体验与成品

沿用[第二十一步评价体系](acceptance/21-user-experience-and-content-quality.md)。不新造满分、不根据代码量给用户体验评分。

| 验收对象 | 下一阶段通过条件 | 当前证据边界 |
|---|---|---|
| 首次上手 | 用户上传图并说目标，能理解下一步和方案，无需开发者代操作或复制长提示词 | 有开发者真实试跑，没有普通用户独立测试 |
| 连续修改 | 能指出一个问题、续改、比较、采用；切换/刷新回到同一工作版本 | 恢复已有验证，统一方案到续改尚需补齐 |
| 商品一致性 | 关键轮廓、颜色、部件、标识与纹理可核对；已知失真不能采用为合格交付 | 白壶AI候选已发现失真并拒绝；放大核对是人工能力 |
| 摄影与用途 | 光影、反光、背景、主次与构图服务于已选买点和用途 | 当前构图改善不等于摄影质量通过 |
| 图文与交付 | 采用图、事实、主稿同版本；口播可试读，外观与购买理由有依据，导出内容准确 | 续作/主稿采用有验证；真实买点反馈和商业成品仍待验 |

开发者先用现有两款茶壶逐条跑通并留证，再邀请非开发者独立完成一次。记录求助次数、复制回填次数、走错入口和主动操作时长；模型等待单独统计。没有实测就不宣称效率提升，也不把审美假设当成已验证的购买理由。
