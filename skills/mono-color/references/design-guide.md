# 单双色设计方法（miniclaw 适配摘要）

Adapted from Yan Liu's mono-color-skill, MIT licensed. Copyright (c) 2026 Yan Liu.
Source commit: c8ff70597ddedcd65f21a0b528f6a70c35690b0a. See ../LICENSE.

本摘要只说明视觉方法。准确配色与规则从同包 design-system/*.json 读取；文件是软件资料，未包含示例图片或第三方参考作品。

- 从主题、意图、准确文字和图片用途出发。一次围绕一个主体组织，复杂主题选择一个具体的视觉关系，不把所有卖点塞满。
- 保持商品、人和场景的身份。抽象表达也需要保留可识别的锚点；不创造商标、包装文字或未经证实的外观细节。
- 默认当代编辑风格。白、灰或淡米色底按对比和主题选择，不自动做成发黄旧纸。
- 受控双色分别承担主墨与强调墨；明确单色时仅一墨。空白纸底不是第三种印刷墨。
- 使用网点、版面分色、轻微套印等印刷语言；避免仅给全彩照片加单色滤镜。
- 一次确定一个主要构图事件，给它留一块安静区域。留白范围参考所选构图目录，不将同一个百分比套给所有主体。
- 标题参与构图。字体角色随内容和语气选择，不强制所有主题用同一种衬线字；单张图内部层级要一致。
- 主体型、标本注释型、大标题型、信息型、物件重复型等构图有不同用途。选择一个结构，其他元素服务于它。
- 新图保持原创，不能复刻参考作品的主体、标题、logo、构图和签名；参考只用于学习空间关系。
- 同一组封面可保持墨色、留白和字号关系，换不同裁切与文字位置；不为随机变化牺牲可读性。
- 图像模型的精确文字可能失真。miniclaw 优先把准确中文标题交给画布文字层，背景与商品纹理按实际能力处理，再由用户核对。
- 可复制的提示词应说明主题、比例、墨色分工、布局、文字和不能改变的事实。算法或模型不能保证完全保真，采用前核对。
