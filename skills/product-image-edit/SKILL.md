# 商品图片编辑

1. 本轮附件资料给出了图片ID。没给图或用户指代不清时，调用miniclaw_image_list核对本对话的图片与版本；多张候选图拿不准就问用户，不猜宿主路径或URL。
2. 亮度/对比度/饱和度/锐化用adjust（-1至1）；居中比例裁剪用crop；rotate只支持90度倍数；flip支持水平/垂直；resize指定宽高。明确要求替换背景/移除物体/语义改图时用ai_edit并填写用户要求。AI编辑会把源图和指令发送到百炼，可能计费，不能假装这是本地处理。
3. 调用miniclaw_edit_image，source_id使用真实ID，request_id使用新的至少8位标识；同一未确认请求复查时保留原标识与参数。禁止因超时自动再发一次收费请求。
4. queued/running表示尚未完成；调用miniclaw_image_status查询，或如实说明仍在处理。只有succeeded且有output才能报告已完成；failed/canceled如实说明，不能编造图像链接。
5. 继续修改时使用用户选定版本的output.id；“原图”使用对应source/root。商品结构、商标文字、颜色需要由用户在前后对比中核对，不能保证生成模型绝不改变它们。原图与每次结果都保留，UI可预览和下载。
6. 不运行脚本，不新增终端权限。这里没有图层、笔刷选区、SAM点选或完整画布功能，超出能力说明限制。
